# Contributing to Tele Tourist

## Branches

### `main`
- Stable project branch.

### `dev`
- Integration branch for combining features.

### `feature/*`
- Individual feature branches.

Examples:
- `feature/auth`
- `feature/explore`
- `feature/story`
- `feature/profile`

## Rules

- Do not directly push feature work to `main`.
- Pull the latest `dev` branch before starting work.
- Create a feature branch.
- Keep commits focused.
- Test changes before pushing.
- Create a Pull Request into `dev`.
- Do not modify unrelated modules.

## Commit Examples

- `feat: add login page`
- `feat: add story API`
- `fix: validate story form`
- `docs: update project structure`
